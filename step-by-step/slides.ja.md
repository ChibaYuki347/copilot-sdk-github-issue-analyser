## スライド 2 - Copilot SDK とは？

**表示タイミング**: ~0:03、SDK の導入中

これは中心となる概念スライドです。視聴者のほとんどはエディタ内の Copilot は知っていますが、SDK は知りません。

**レイアウト案**: 2 列、または前後比較のビジュアル

| エディタ内の Copilot | Copilot SDK |
|---|---|
| VS Code、JetBrains などに組み込まれています | インストールして使う Python / JS / C# ライブラリです |
| 入力中にコードを提案します | あなたのアプリケーションが他のライブラリと同じように呼び出します |
| 画面上で結果を見ます | あなたのコードが結果を受け取り、何をするかを決めます |
| 開発者向けのツールです | アプリケーションの構成要素です |

**これは何か**:
- コードの中で `requests` や `pandas` のように import するライブラリです
- あなたのアプリがプロンプトを送り、テキストを受け取ります。そのあと、それをどう扱うかはあなたのコードが決めます
- データを取得したりアクションを実行したりするために呼び出せるツール (関数) を与えられます
- それはあなたのアプリの中で動作します。Web サーバー、CLI スクリプト、GitHub Action、Slack bot などです

**これは何ではないか**:
- チャットボットではありません。自分で作らない限り、チャットウィンドウはありません
- 意識を持っているわけではありません。パターンに基づいてテキストを生成するのであって、「理解」したり「望んだり」しているわけではありません
- 魔法ではありません。明示的に与えたツールしか使えません
- 自律的ではありません。開始するのも、停止するのも、アクセスできる範囲を制御するのも、あなたのコードです

**3 つの構成要素** (アイコンまたは簡単な図):

1. **Client (クライアント)** - Copilot バックエンドに接続します (データベース接続のようなものです)
2. **Session (セッション)** - モデル、ツール、指示を設定する会話スレッドです
3. **Tools (ツール)** - 実行中にモデルが呼び出せる、あなたが書く通常の関数です

**キーメッセージ**: 「SDK を使うと、Copilot を自分のアプリケーションに組み込めます。何ができるかはあなたが定義します。制御権はあなたのコードが持ちます。」

## スライド 3 - エージェント型ループ

**表示タイミング**: ~0:16、フェーズ 3 (ツール) の直前、または ~0:31 の最初のライブ解析の直前

ツール呼び出しループがどのように動くかを示す、シンプルなフロー図です:

```
プロンプト → モデルがレスポンスを生成 → レスポンスにツール呼び出しを含む → ツールを実行 → 結果を返す → モデルが再度生成 → ... → 最終テキストレスポンス
```

**ビジュアル案**: これらのノードを持つループ / サイクル図:

1. 📝 **プロンプトを送信** - 「この GitHub Issue を解析してください」
2. 🔧 **モデルがツール呼び出しを要求** - たとえば `get_github_issue`
3. ⚙️ **ツールを実行** - あなたのコードが実行され、データを返します
4. 📖 **結果を返す** - モデルがツールの出力を受け取ります
5. ↩️ **ループ** - モデルがさらにツール呼び出しを要求するか、最終出力を生成します
6. ✅ **最終レスポンス** - 構造化された評価が返されます

**キーメッセージ**: 「シーケンスをスクリプトで固定しているわけではありません。モデルは、必要な情報に基づいてツールを選択します。」

## スライド 4 - 構築したもの (アーキテクチャ)

**表示タイミング**: ~1:05、まとめの間 (または ~0:41 にフェーズ 5 の前に短く)

完成したシステムのシンプルなアーキテクチャ図です:

```
┌──────────────────────────────────────────┐
│  ブラウザー (ビルド済みフロントエンド)    │
│  EventSource → チャットバブルを描画       │
└────────────────┬─────────────────────────┘
                 │ SSE (Server-Sent Events)
                 ▼
┌──────────────────────────────────────────┐
│  FastAPI サーバー (app.py)               │
│  /analyse/stream + /post-analysis        │
│  非同期キューが SDK → SSE を橋渡し       │
└────────────────┬─────────────────────────┘
                 │ Copilot SDK
                 ▼
┌──────────────────────────────────────────┐
│  Copilot バックエンド (gpt-4.1)          │
│  レスポンスとツール呼び出しを生成         │
└────────────────┬─────────────────────────┘
                 │ ツール呼び出し
                 ▼
┌──────────────────────────────────────────┐
│  GitHub REST API                         │
│  Issues · Contents · コード検索          │
└──────────────────────────────────────────┘
```

**キーメッセージ**: 「1 つのファイルに、4 つのレイヤーがあります。SDK は中央にあり、UI をモデルとツールに接続します。」
