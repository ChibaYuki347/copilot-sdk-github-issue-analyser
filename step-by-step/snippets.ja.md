app.py — GitHub Issue 複雑さ解析ツール

使い方:
  python app.py hello                          # Phase 2a: 最もシンプルな SDK 呼び出し
  python app.py hello-stream                   # Phase 2b: ストリーミングイベント

  python app.py <owner> <repo> <issue_number>  # Phase 4: CLI で解析
  python app.py serve                          # Phase 5: Web UI を起動
  python app.py post <github_issue_url>        # Phase 6a: 解析してコメントとラベルを投稿

LANG=ja (または APP_LANG=ja) を付けると、System Prompt と CLI 表示が日本語になります。

## ライブ配信用ショートカット (チャットに貼る用)

ライブ配信中に視聴者へ案内するときに使う一行コマンドです。チャット欄にコピペできます。

```
# 日本語版リポジトリ:
https://github.com/ChibaYuki347/copilot-sdk-github-issue-analyser/tree/ja

# 日本語スクリプト全文:
step-by-step/script.ja.md

# 用語集:
step-by-step/glossary.ja.md

# 起動コマンド (日本語 UI):
APP_LANG=ja python app.py serve   # http://localhost:8000/?lang=ja

# 起動コマンド (英語 UI / upstream と同じ):
python app.py serve               # http://localhost:8000/
```

## 翻訳・編集の方針

- **直訳寄り** + ですます調 + 用語は `glossary.ja.md` に統一
- コード内の関数名・変数名は英語のまま (プログラミング教材としての可搬性のため)
- スキルレベルは「ジュニア / ミドル / シニア / シニア+」とし、**年次ではなくコードベースへの習熟度**である旨を口頭でも明示する
- 上記コメントは IDE のスニペット (User Snippets) として登録しておくと、ライブ写経時に短いプレフィックスから展開できて便利です
